# JP Tracker

App personal de nutrición, entrenamiento, ayuno y seguimiento digestivo.

## Instalación en Android

1. Abrí el link de GitHub Pages en Chrome
2. Esperá unos segundos hasta que aparezca el banner "Añadir a pantalla de inicio"
3. Si no aparece: menú ⋮ → "Instalar aplicación" o "Añadir a pantalla de inicio"
4. Listo, se instala como app standalone
